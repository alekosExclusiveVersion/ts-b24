Авторизация API PC — заголовок Authorization: <ключ> (в спецификации securitySchemes.ApiKey = name: Authorization), а не ApiKey. Ключ привязан к белому списку IP, текущий адрес 2.27.27.160 в него не входит.

Возможные причины «не работает API китайских каталогов» у tsk-market.kz:

  • 403 — сервер kz1 (или боевой IP клиента) не в allow-list ключа / IP сменился;
  • 401 — неверный формат ключа (заголовок ApiKey вместо Authorization, неверный/истёкший TWS-ключ);
  • 400/422 — некорректные carId/groupId/branchId в запросах из вложения;
  • лимиты/изменение версии API (v1.18.0).
Примечание: содержимое вложения (GET-запросы клиента) на момент подготовки карточки не прочитано — раздел 6 дополнить реальными URL и кодами ответов, прогнав их с IP, разрешённого для ключа. Рекомендуется получить доступ к файлу (сессия B24, fileId 1914463) до финализации карточки.
